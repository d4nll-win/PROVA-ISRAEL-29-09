# Projeto Discord

Este projeto foi desenvolvido como uma atividade da disciplina de HTML, com o objetivo de colocar em prática os principais conceitos aprendidos durante as aulas.

A ideia foi criar um pequeno site sobre o **Discord**, mostrando um pouco sobre a plataforma, seus recursos, chamadas, transmissões e também alguns dos sons característicos que fazem parte da experiência de usar o aplicativo.

## Sobre o projeto

O site foi desenvolvido utilizando apenas **HTML**, sem a utilização de CSS. A proposta foi justamente trabalhar a estrutura e a semântica das páginas utilizando as próprias tags do HTML.

Durante o desenvolvimento, foram utilizadas diferentes tags e recursos, como:

* `header`
* `nav`
* `main`
* `section`
* `article`
* `aside`
* `footer`
* `figure` e `figcaption`
* `details` e `summary`
* `table`
* `form`
* `audio`
* `video`
* `abbr`
* `mark`
* `del` e `ins`
* `blockquote`
* `progress`
* `meter`
* `time`

Também foram utilizados recursos como `datalist`, campos de formulário com `required`, `placeholder`, seleção de arquivos, data e escala de valores.

## Páginas

O projeto possui cinco páginas principais:

* **Início** — apresenta o que é o Discord e um pouco da história e utilização da plataforma.
* **Recursos** — mostra algumas das principais funções disponíveis no Discord.
* **Chamadas e Transmissões** — explica os recursos relacionados a chamadas de voz, vídeo e compartilhamento de tela.
* **Sons do Discord** — apresenta alguns sons característicos da plataforma e situações em que eles podem aparecer.
* **Formulário** — reúne elementos de formulário e permite registrar uma opinião sobre a experiência com a plataforma.

Todas as páginas possuem um menu para facilitar a navegação entre elas.

## Tecnologias utilizadas

* HTML5
* Git
* GitHub

O projeto foi feito sem CSS, seguindo a proposta da atividade de trabalhar principalmente os recursos e a estrutura do HTML.
